# Software Installation Request Policy
Effective Date: 2024-03-01

## Approved Software
Employees can install approved software directly from the Company Portal app on their laptops. This includes standard tools like Zoom, Slack, and Google Chrome.

## Unapproved Software
Any software not in the Company Portal requires managerial approval. You must submit a ticket to the IT Help Desk. IT will review the software for security vulnerabilities before installation. Under no circumstances should employees download pirated or unlicensed software.
