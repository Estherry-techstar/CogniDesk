# Acme Corp Password Reset Policy
Effective Date: 2024-01-01

## Self-Service Reset
Employees can reset their passwords using the Self-Service Password Reset (SSPR) portal. You must have MFA enabled to use SSPR.

## Requirements
Passwords must be at least 14 characters long, contain one uppercase letter, one number, and one special character. Passwords expire every 90 days.

## Help Desk Escalation
If you are locked out and cannot use SSPR, contact the IT Help Desk. You must verify your identity via a video call before your password is reset.
