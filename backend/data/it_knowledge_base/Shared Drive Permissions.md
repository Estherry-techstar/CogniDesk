# Shared Drive Access Policy
Effective Date: 2024-02-01

## Requesting Access
To access a new department's shared drive (e.g., Finance Share), you must submit a ticket to the IT Help Desk. You must include your manager's written approval in the ticket.

## Permissions
Read-Only access is granted by default. Write access is only granted if your job role explicitly requires editing files within that share. IT reviews permissions quarterly.
