# Acme Corp Printer Connectivity Guide
Effective Date: 2024-02-15

## Standard Setup
To connect to a floor printer, open Windows Settings > Devices > Printers & Scanners. Click "Add a printer" and select your floor's printer from the list (e.g., HR-Floor3-HP).

## Common Issues
If the printer is not showing up, ensure you are connected to the "Acme-Corp-Secure" Wi-Fi network. If you get a "Driver Unavailable" error, please submit a ticket to the IT Help Desk to have the driver pushed to your machine.
